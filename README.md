# RenPlay Runner — แอปพลิเคชันรันเกม Ren'Py ของ PC บนมือถือ (แบบเดียวกับ JoiPlay)

**RenPlay Runner** เป็นแอปพลิเคชันสำหรับเปิดเล่นเกมแนว Visual Novel ที่สร้างด้วยเอนจิน **Ren'Py (PC)** บนสมาร์ตโฟนระบบ Android โดยใช้หลักการทำงานเดียวกับ **JoiPlay**

---

## 🎮 หลักการทำงานของ JoiPlay และ RenPlay

เกม Ren'Py บน PC (Windows/Linux/Mac) นั้นไม่ได้เขียนด้วยภาษา C++ ล้วนที่ต้องพึ่งพา Windows x86 เสมอไป แต่สร้างขึ้นจาก:
1. **Python Bytecode (`.rpyc`)**: สคริปต์ของเกม Ren'Py จะถูกคอมไพล์เป็นไบต์โค้ดของ Python
2. **Assets**: โฟลเดอร์ `game/` ประกอบไปด้วยภาพ (`.png`, `.webp`), เสียง (`.ogg`, `.mp3`), และไฟล์แพ็กเกจ (`.rpa`)

### สถาปัตยกรรม 2 ส่วน:
* **ส่วนที่ 1: หน้าบ้าน (Front-End & Virtual Controls - แอปนี้)**
  * จัดการคลังเกม (ค้นหา, แสดงหน้าปก, บันทึกเวลาเล่น)
  * สแกนโครงสร้างโฟลเดอร์เกมของ PC ตรวจสอบความถูกต้องของสคริปต์
  * สร้าง **ปุ่มสัมผัสเสมือน (Virtual Gamepad Overlay)** บนหน้าจอมือถือโดยเฉพาะสำหรับ Visual Novel เช่น:
    - **ESC**: เปิดเมนู Save/Load/ตั้งค่าของเกม
    - **SKIP (Ctrl)**: ข้ามบทสนทนาที่อ่านแล้วอย่างรวดเร็ว
    - **AUTO**: เปิดโหมดอ่านบทสนทนาอัตโนมัติ
    - **BACK (Page Up)**: ย้อนดูประโยคสนทนาก่อนหน้า (Rollback)
    - **HIDE (H)**: ซ่อนกรอบข้อความเพื่อชมภาพ CG เต็มจอ
    - **NEXT (Enter/Space)**: กดไปบทสนทนาถัดไป
* **ส่วนที่ 2: เอนจินรัน Python (Execution Engine / JoiPlay Plugin)**
  * รันสคริปต์ไพทอนผ่าน Native C Libraries (`libpython`, `libsdl2`) โดยเชื่อมต่อกับ Plugin (เช่น JoiPlay Ren'Py Plugin หรือ RAPT) ผ่าน Android Intent Bridge

## 📱 วิธีนำเกม Ren'Py จาก PC มาเล่นในแอปนี้

1. **คัดลอกเกมจาก PC มาไว้ในมือถือ**:
   - นำโฟลเดอร์เกมของ PC (ที่มีโฟลเดอร์ `game/` และไฟล์ `.exe`) มาวางไว้ในมือถือ เช่น ในโฟลเดอร์ `Download/`
2. **เปิดแอป RenPlay Runner**:
   - กดปุ่ม **"เพิ่มเกม" (+)** ที่มุมขวาล่าง
   - เลือกโฟลเดอร์เกม หรือเลือกไฟล์ `.exe` ของเกม
   - แอปจะตรวจจับไฟล์สคริปต์ ดึงภาพหน้าปก และเพิ่มเกมเข้าคลังอัตโนมัติ
3. **ติดตั้ง Ren'Py Plugin (ทำครั้งเดียว)**:
   - ไปที่เมนูตั้งค่าในแอป แล้วกดปุ่มดาวน์โหลด Ren'Py Plugin (เอนจิน Python/SDL2)
4. **กดเล่นเกม**:
   - กดปุ่ม Play ที่การ์ดเกม เพื่อเริ่มเล่นพร้อมปุ่มสัมผัสเสมือนบนหน้าจอได้ทันที

## 🛠️ วิธี Build เป็นไฟล์ APK ผ่าน GitHub Actions

1. ดับเบิลคลิกที่ไฟล์ `push_to_github.bat`
2. วางลิงก์ GitHub Repository ของคุณ
3. รอระบบคลาวด์ GitHub Actions สร้างไฟล์ APK ประมาณ 3–5 นาที
4. เข้าไปดาวน์โหลดไฟล์ `app-release.apk` จากแท็บ **Actions** บน GitHub ได้ทันที!
